# Flutter Lab Project - Android APK

This repository contains the Android APK build for the Flutter project.

## Download & Installation
- [app-debug.apk](app-debug.apk) (Managed with Git LFS)

### Installation Notes:
1. Enable **"Install unknown apps"** in your Android device settings if prompted.
2. If prompted by Google Play Protect, select **"More details"** -> **"Install anyway"**.
